# 显示与恢复

运行时配置和数据目录必须一致：

```powershell
$env:PROGRESS_CARD_HOME = 'D:\TaskCardData'
$env:PROGRESS_CARD_PORT = '43128'
node '<skill-dir>\scripts\server.mjs'
```

服务前台运行，停止所属进程即可停服；页面关闭不会删除状态卡。若由 Codex 启动，使用其可管理的进程会话，或系统支持的隐藏后台启动方式，并保存启动归属。Windows 的后台 Start-Process 必须使用 WindowStyle Hidden。不要安装系统服务或开机自启，不终止其他 Node 进程。端口被占用时核实归属或明确选择另一端口，不自动杀进程抢占端口。

页面、服务、entry.mjs 必须使用同一 PROGRESS_CARD_PORT。默认 43128，仅监听 127.0.0.1。已有原版服务仍在使用该端口时，不用新包覆盖它；试用选择独立数据目录和端口。

`node scripts/entry.mjs` 返回本对话的入口。它不启动服务、不写卡、不自动打开页面。无可靠 CODEX_THREAD_ID 时停止对话定位；可提供明确的原卡文件预览，不猜测用户正在查看的任务。

Codex 原生 `open_in_codex` 可用时，使用返回 url、placement=right，在调用任务打开。其他运行环境可在本机浏览器打开。不要把网页内工具栏误称为客户端输入框按钮；关闭标签后的重新打开需要现有入口或执行者操作。

页面功能：

- 当前任务：主线、当前动作、临时回补、返回点；已完成步骤可展开看依据和登记资料。
- 本对话记录：关键词、完结状态、月份和首尾日期筛选；日期统一按 Asia/Shanghai。
- 档案：项目位置、已登记原文、Markdown 阅读版；点击才读取具体资料。
- 只读原卡：页面约每 2.5 秒读取一次，隐藏时暂停。已连接表示服务可用，不代表 AI 正在工作。

Windows 的“打开项目文件夹”只打开已登记目录；其他系统返回功能不可用，卡片和资料阅读仍可使用。返回成功只表示已发起打开请求，不证明文件窗口已呈现。

localhost 服务不是多用户权限系统。对话编号用于正确路由，不能当密码；本机有访问能力的程序可能读取已登记内容。不要通过隧道、公网监听或端口转发暴露该服务。

关闭/刷新/重启读取原文件，不重新初始化进度。视图筛选和展开偏好不是状态卡，浏览器清理后可丢失；实际业务状态仍在原文件。没有真实改动不为刷新页面写卡。
