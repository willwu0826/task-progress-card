# 本次发布范围

0.1.0 提取已用于真实项目的状态引擎与页面，发布包进一步移除了机器专属路径、真实对话编号、真实任务数据和依赖真实数据的测试。

提供：主线与多层回补分离、返回点恢复、验收后完结、原卡历史、旧格式只读投影、对话范围查询、步骤依据、项目资料追溯、Markdown 安全阅读、按时间查询。

不包含：用户真实卡片/合同/历史、全项目发现器、旧悬浮列表、硬件钩子、双对话试用钩子、全局 AGENTS 修改、自动模型调用、跨任务消息、固定按钮和全对话自动接入。

原生顶部项目动作按钮保留为候选。后续需单独验证当前对话身份、关闭后恢复和跨项目覆盖；本版安装不代表这些功能已实现。Skill 的自动选用也不等于客户端后台监控。

页面与工具按已登记来源工作。未知资料不补造，正确维护仍需执行者核实事实。测试覆盖技术行为，不能替代具体业务验收，也没有测量或承诺节省 token 的比例。

项目自产代码、marked 阅读组件和原始业务数据分开管理；marked 的 MIT 声明保留在 assets/web/vendor/marked.LICENSE.md。发布仓库不含原始业务数据。
